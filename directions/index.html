Plan4Planet identity: three directions (v3)

Each direction is a complete system: mark, wordmark, palette, type pair, and three applications (website hero, link-preview tile, speaker card). The identity is for Plan4Planet as a continuing community, so nothing in it names the 2026 symposium or AAAI; those belong on event pages and templates built with it.

Each one is also applied to the real site. Open the link at the end of a panel; the choice is remembered per tab, so you can keep three tabs open and compare.

A. Chosen path

A search tree with one route picked out: the thing a planner actually computes, and still a tree, so it keeps a thread of continuity with the symposium's first logo. Academic, warm, a little playful.

Fits

The planning community recognises itself; approachable for practitioners; distinct from AAAI navy and from generic climate-tech green. The tree keeps continuity with the first logo without its clutter.

Risks

Orange on green can read "outdoorsy" if overused, so the ember stays on one element per surface. The tree must keep its one highlighted path or it becomes a generic network diagram.
